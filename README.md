# NLP Project

Coursework notebooks exploring transformer-based NLP models, including fine-tuning and masked language modeling with BERT and LLaMA 3.

## Notebooks

| Notebook | Description |
|---|---|
| `NLP_Project_Task1.ipynb` | Task 1 baseline / initial exploration |
| `NLP_Project_BERT.ipynb` | BERT model fine-tuning |
| `NLP_Project_BERT_MLM.ipynb` | BERT masked language modeling |
| `NLP_Project_llama3.ipynb` | LLaMA 3 experiments |
| `nalapro_bonus_llama3_lora.ipynb` | Bonus: LLaMA 3 fine-tuning with LoRA |

## Requirements

- Python 3.x
- Jupyter Notebook
- `transformers`, `torch`, `datasets` (install via `pip install -r requirements.txt` if provided)

## Usage

Clone the repo and open any notebook in Jupyter:

```bash
git clone <repo-url>
cd nlpProject
jupyter notebook
```

Each notebook is self-contained and can be run top to bottom.
